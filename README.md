# Insurance Policy Details Dashboard

A sample policy details dashboard built with React (JavaScript) and Vite, using dummy data.

## Sections

- Sum assured (base, rider and total cover)
- Insured details
- Policy holder
- Beneficiaries / nominees with share split
- Contact information
- Address of correspondence
- Broker details
- Medical and non-medical disclosures (tabbed)
- Premium breakdown and payment history
- Add-ons / riders
- Free benefits

All data lives in `src/data/policyData.js` and is fictitious.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`. Requires Node 16+.
